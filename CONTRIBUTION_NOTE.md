# 👥 Team & Contributions

MerchantLens was built by two collaborators who share the same name — both named Atul Kumar — so contributions are identified by role.

## Atul (Product)

Led product vision, user experience, and product strategy from the ground up. Responsibilities included:

- Defining the core merchant problem around AI shopping agent visibility
- Designing the AI readiness scoring framework and merchant-facing workflows
- Designing the landing page, dashboard UI, and Analyze experience
- Engineering and refining the LLM prompts powering the analysis pipeline
- Leading documentation, product positioning, and deployment

## Atul (Engineering)

Led backend implementation, infrastructure, and system reliability. Responsibilities included:

- Building all serverless API routes:
  - `/api/analyze`
  - `/api/analyze-file`
  - `/api/trust_check`
  - `/api/policy_analyze`
  - `/api/schema`
- Implementing file parsing and OCR processing flows
- Handling frontend error states, validation, and edge-case management
- Building the complete Toolkit system, including both frontend interfaces and supporting APIs

## Shared Contributions

Frontend development and product integration were collaborative efforts.

- The Dashboard and Analyze workflows (score cards, tab views, sidebar, export modal, history panel) were primarily driven by Atul (Product)
- The Toolkit UI and utility workflows were primarily driven by Atul (Engineering)

Both contributors collaborated on:
- overall frontend architecture
- styling and UI consistency
- prompt iteration
- feature prioritization
- product scope decisions
- ensuring the platform felt cohesive as a single merchant-facing experience
